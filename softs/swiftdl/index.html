High-Performance Engineering

Designed for Power, Built for Mac

Everything you expect from an elite download accelerator, packaged with the simplicity and elegance of native macOS architecture.

⚡

8x Segmented Acceleration

SwiftDL splits target files into 1, 2, 4, or 8 parallel chunks utilizing HTTP Range headers. Each segment streams concurrently over independent connections and writes directly into pre-allocated file blocks, maximizing bandwidth utilization.

🚦

Dynamic Speed Limiter

Keep your Zoom meetings, 4K video streams, and online gaming silky smooth. A precision sliding-window token bucket algorithm throttles download bandwidth on-the-fly with quick presets (500 KB/s, 1 MB/s, 2 MB/s, 5 MB/s) or your custom rate.

⏱️

Smart Queue Scheduler

Schedule heavy downloads to execute during off-peak hours (e.g., 1:00 AM – 6:00 AM). Select specific active days of the week, automate queue start/stop sequences, and receive local macOS notifications upon batch completion.

🎥

YouTube & Video Downloader

Integrated support for online media via automatic detection of yt-dlp across Homebrew, Python framework paths, and standard binaries. Download video streams directly through the same unified queue.

📋

Instant Clipboard Integration

Copy any download link in Safari or Chrome, and SwiftDL auto-detects valid URLs upon focus. Paste instantly into the top quick-bar or tap the add button to configure thread count and target folder.

📂

Automated File Organization

Incoming downloads are automatically classified into intuitive categories: Applications (dmg, pkg), Archives (zip, rar, 7z, iso), Movies (mp4, mkv), Music, and Documents.

🔄

Pause, Resume & Auto-Retry

Never lose download progress to spotty Wi-Fi or accidental drops. SwiftDL persists segment byte offsets to disk, enabling instant resume for servers supporting HTTP byte ranges without redownloading from scratch.

🛡️

100% Sandboxed & Safe

Strictly compliant with Apple App Store Review Guidelines and macOS App Sandbox security. All file operations remain confined to user-selected directories with zero background privilege escalation or kernel extensions.

Under the Hood

Engineered with Swift 6 Concurrency

A modern system architecture built without third-party bloat, memory leaks, or legacy baggage.

⚡ Segment Chunk Engine

  • HTTP HEAD probe detects file size and Accept-Ranges: bytes capability.
  • Pre-allocates final file on disk via low-level FileHandle.truncate(atOffset:).
  • Fires concurrent URLSessionDataTask workers writing at calculated byte offsets.
  • Automatic fallback to reliable single-stream download if server lacks range support.

🚦 Token-Bucket Throttling

  • Thread-safe NSLock protected sliding 1.0-second time window.
  • Calculates microsecond delay when incoming packet volume exceeds rate quota.
  • Zero packet drops and smooth network coexistence for video calls & cloud backups.
  • Immediate parameter tuning without restarting or pausing active download streams.

🍎 Native macOS Integration

  • 100% pure SwiftUI reactive state powered by Combine and Swift Concurrency actors.
  • Apple Silicon M-series optimized with near-zero idle CPU and memory consumption.
  • Rich contextual menus, Finder file reveal (selectFile:inFileViewerRootedAtPath:).
  • Full dark & light mode adaptation obeying macOS appearance settings.
