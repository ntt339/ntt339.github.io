Privacy Policy

Last Updated: October 26, 2026

Summary: MiniStats does not collect, store, transmit, or share any personal data, analytics, or hardware telemetry. Everything operates 100% locally on your Mac with zero internet communication.

1. Overview

MiniStats ("the Application", "we", "our") is designed by THANG TRUONG NGOC as a lightweight, privacy-first system monitoring utility for macOS. We firmly believe that your hardware statistics, running applications, and system performance telemetry belong exclusively to you.

2. Data Collection and Usage

We do not collect any personal data whatsoever.

  • No Personal Information: We do not ask for, gather, or store your name, email address, IP address, device serial numbers, or location.
  • No Telemetry or Analytics: The Application contains no third-party tracking frameworks, crash analytics SDKs, or behavioral trackers (no Google Analytics, no Firebase, no Facebook SDK, etc.).
  • No User Identification: We do not generate unique identifiers or track user interaction patterns.
  • No Network Transmission: MiniStats operates entirely offline and makes zero remote network connections.

3. Local System Metrics

To perform its core functions, MiniStats queries macOS hardware and system APIs strictly in real-time, volatile memory (RAM):

  • CPU & GPU Metrics: Core utilization percentages, Performance vs. Efficiency core breakdown, and hardware temperature sensor readings via Apple SMC and IOKit.
  • Memory (RAM): Real-time breakdown of used memory versus total physical system capacity.
  • Physical Network Counters: Physical interface byte counters (Wi-Fi, Ethernet) to display live upload and download rates.
  • Power & Battery: Battery percentage, charging/discharging wattage in Watts (`W`), adapter specifications, and runtime estimates.
  • Storage Partitions: Mounted internal volume names and remaining capacity via macOS standard `FileManager` APIs.
  • Running Processes: Ephemeral queries of running application names, CPU%, and memory using Darwin `proc_pidinfo` to display top resource-heavy applications. This inspection occurs solely in volatile RAM while the popover is actively displayed.

Important: All readings are strictly computed on-device in transient volatile memory. None of these readings are ever written to persistent remote storage, logged to disk, or transmitted over any network.

4. Local Notifications & Permissions

MiniStats includes an optional Smart Battery Reminder feature that notifies users when their battery drops below specific thresholds (50%, 40%, ≤30%).

  • Notifications are dispatched 100% locally on your Mac using Apple's native `UNUserNotificationCenter` framework.
  • No remote Apple Push Notification service (APNs) or third-party notification servers are used.
  • You can disable battery reminders at any time in the app's Settings panel or through macOS System Settings.

5. Network Permissions & Sandbox

MiniStats runs inside Apple's strict App Sandbox environment. The network client entitlement is configured solely to query physical network interface byte counters via native Darwin socket APIs. MiniStats makes zero remote server connections and transmits zero bytes of data outside your computer.

6. In-App Purchases & Pricing

MiniStats is 100% free. It contains no in-app purchases, no subscriptions, no paywalls, and no third-party advertisements.

7. Children’s Privacy

Because MiniStats does not collect any personal information from anyone, it complies with COPPA (Children’s Online Privacy Protection Act) and does not gather data from children under any age.
